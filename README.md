One image that sums up the world's news of Friday, 20 November 2026: a front page drawn from the day's wires — a Russian missile inside Poland, the Trump–Xi–Putin peace declaration weighed by capitals, Anthropic's second day as a public company, GTA VI's record launch, a fresh UK–EU deal, the end of America's measles-elimination status — with the day's shorter stories along the foot. Built and drawn by an AI agent, with every headline verified against two wire services the same day.

## Run it

```sh
node main.ts
# the image lands at /output/entry.png (MAKEFUN_OUTPUT_DIR stands in for /output outside the grader)
```

No network and no dependencies: the Node 22 standard library alone, and the same bytes on every run. The picture ships in the repository at `entry.png`; the program's job is to place it, unchanged, where the grader reads it.
